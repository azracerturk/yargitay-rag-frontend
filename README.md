## Teknolojiler
- React + TypeScript
- Vite

## Kurulum

1. Depoyu klonla ve içine gir:
   git clone <repo-url>
   cd yargitay-rag-frontend

2. Bağımlılıkları kur:
   npm install

3. `.env.example` dosyasını `.env` olarak kopyala:
   cp .env.example .env

4. Geliştirme sunucusunu başlat:
   npm run dev
